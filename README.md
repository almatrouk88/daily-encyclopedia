# الموسوعة اليوميّة 📚

كتاب قراءة إلكترونيّ متجدّد: مقالةٌ موثوقة كلّ يوم في شتّى المجالات (علوم، تاريخ، فلسفة، فنون، مهارات…).
مبنيّ على محرّك قارئ «مجلة الرسالة»، مهيّأ للجوّال وأجهزة الحبر الإلكترونيّ.

**اقرأ:** https://almatrouk88.github.io/daily-encyclopedia/

المحتوى مُصاغ من مصادر موثوقة (تُذكر في كل مقالة). البناء: `node build.mjs` (يقرأ `entries/*.json`).
